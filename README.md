# PLITAP · Документация

Объяснения и руководства для людей, которые знакомятся с PLITAP, используют его или создают интеграции.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Понятное описание основных понятий и пользовательских сценариев.
- Руководства разработчикам и участникам сети.
- Ответы на вопросы и переводы подготовленных материалов.

## Границы направления

Обязательные правила находятся в [spec](https://github.com/Plitap/spec). Инструкции сборки конкретного компонента остаются рядом с его кодом. Документация ссылается на точные версии правил и реализаций, когда они опубликованы.

## Структура

| Раздел | Назначение |
|---|---|
| [`concepts/`](concepts/) | Пояснения основных понятий и связей между частями PLITAP. |
| [`users/`](users/) | Руководства по пользовательским сценариям опубликованных приложений. |
| [`developers/`](developers/) | Порядок знакомства с протоколом и создания интеграций. |
| [`operators/`](operators/) | Руководства для участников, запускающих узлы сети. |
| [`faq/`](faq/) | Ответы на повторяющиеся вопросы с указанием актуального статуса. |
| [`translations/`](translations/) | Переводы с обозначением языка и версии исходного документа. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/docs/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
